# Supplementary license sources

Complete license texts and exact copyright notices omitted by the crates.io
archives or by filename-based scanning. Upstream sources are pinned to the
published crates’ `.cargo_vcs_info.json` revisions; font license texts and Khronos
XML inputs were also compared byte-for-byte with the locked crate sources.

The egui family here is ecolor, eframe, egui, egui-wgpu, egui-winit, egui_glow,
emath, epaint and epaint_default_fonts, all version 0.33.3. The font notices apply
to the four fonts actually embedded by epaint_default_fonts.

`manifest.json` maps each preserved text to exact crate versions, primary source
URLs and its SHA-256. These files supplement `THIRD_PARTY_NOTICES.md`; retain both
in binary packages. No font files, camera firmware or proprietary software are
included in this directory.

gl-rs source headers retain their Apache-2.0 attribution. The font copyright
notice preserves the Noto/Ubuntu copyright and trademark fields from the actual
font files because those statements are absent from their standalone license
